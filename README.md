# UI Kit Help Desk

## Descripción
Biblioteca de componentes UI desarrollada con HTML5 y CSS3 para el sistema Help Desk. El proyecto implementa componentes reutilizables para mantener una interfaz uniforme y adaptable.

## Componentes incluidos

### Botones
- Crear Ticket
- Actualizar Ticket
- Eliminar Ticket
- Enviar Ticket

### Formularios
- Campo de texto
- Campo de correo electrónico
- Lista desplegable (Select)
- Área de texto (Textarea)

### Tarjetas (Cards)
- Tarjetas para mostrar información de tickets

### Alertas (Badges)
- Prioridad Alta
- Prioridad Media
- Prioridad Baja

## Tecnologías utilizadas
- HTML5
- CSS3
- Git
- GitHub

## Características
- Diseño responsive mediante Media Queries.
- Uso de variables CSS.
- Componentes reutilizables.
- Estados de interacción mediante :hover y :focus.

## Estructura del proyecto

```text
UI_KIT_HELPDESK/
│
├── INDEX.HTML
├── STYLE.CSS
└── README.MD
```

## Funcionalidades
- Registrar tickets de soporte.
- Enviar tickets mediante formulario.
- Visualizar tickets en tarjetas.
- Identificar prioridades mediante etiquetas de colores.
